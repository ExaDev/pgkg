# Architecture Decision Records

Numbered, append-only records of architectural decisions. Each ADR states the context that
prompted the decision, the decision itself with rejected alternatives, and the consequences.

Superseding an ADR means writing a new one and marking the old one `Superseded by ADR-NNNN` —
never editing history.
